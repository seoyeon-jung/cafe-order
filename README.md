# 카페 주문 금액 계산기
카페 메뉴를 선택하고 수량에 따라 주문 금액을 계산하는 Java 콘솔 프로그램입니다.

## 주요 기능
- 메뉴별 가격 조회
- 주문 금액 계산

## 기술 스택
- Java
- Gradle 8.10 (Wrapper 포함)

## 메뉴
| 메뉴 | 가격 |
|------|------|
| 아메리카노 | 3,000원 |
| 라테 | 4,000원 |

- 등록되지 않은 메뉴 또는 `null`: 가격 0원
- 수량이 0 이하: 총액 0원

## 프로젝트 구조
```
src/main/java
├── Main.java            # 주문 실행 및 결과 출력
├── Menu.java            # 메뉴 가격 조회
└── OrderCalculator.java # 주문 금액 계산
```
